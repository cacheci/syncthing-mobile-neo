# Syncthing GUI

一个 Kotlin Multiplatform Syncthing 控制界面。

## Android

- Application ID：`moe.https.syncthing`
- `compileSdk`：37
- `targetSdk`：28
- `minSdk`：28
- 支持的核心架构：`arm64-v8a`
